## 🎉 PARTY MODE

Press the **party** button, pick how long (5–60 min), and Chippy takes over: an endless run of fresh **64-bar songs**, each a random genre and pattern, one after another until the timer's up. Every song has a real arc — a sparse intro, a build, a full drop, a breakdown with the kick pulled, another build and drop, then an outro — so it plays like a set, not a loop. When the clock runs out it winds down and hands you back manual control.

The button is meant to be pressed — it breathes with a soft squishy pulse. While the party's live it turns green and shows the countdown and which bar of 64 you're on. Chippy's face vibes along the whole time.

## EVERYTHING ELSE

House / Breaks / Drum & Bass / Big Room · 7-voice chiptune engine · scrolling piano roll · WAV export · tempo & swing wheels · Chippy's reactive face. Single file, no dependencies, offline.

## REQUIREMENTS

Any modern browser (Chrome recommended). No install, works offline. Audio starts on first click.
